# Cara pasang NJH Offline (APK debug) di HP Android

**File:** `NJH-offline-debug.apk` (sekitar 13 MB, versi 0.1.0-offline, sha256 diawali 5a4798e8f017a0dd)
Gamenya jalan **tanpa internet** dan **tanpa login**. Progres tersimpan otomatis di HP.

## Langkah pasang
1. Kirim file `NJH-offline-debug.apk` ke HP (lewat Google Drive, WhatsApp "Dokumen", kabel USB, dll).
2. Di HP, buka file APK-nya, misalnya dari aplikasi **Files/File Manager** atau dari notifikasi download.
3. Kalau muncul peringatan *"Untuk keamanan, HP tidak diizinkan memasang aplikasi dari sumber ini"*:
   - Tap **Setelan**, lalu nyalakan **Izinkan dari sumber ini** (*Install unknown apps*) untuk aplikasi yang dipakai buka APK (Files/Chrome/Drive/WhatsApp).
   - Tekan tombol kembali, lalu tap **Pasang/Install**.
4. Kalau Play Protect nanya *"Aplikasi tidak dikenal"*, pilih **Tetap pasang** (*Install anyway*). Ini APK debug yang belum lewat Play Store, jadi peringatan ini normal.
5. Buka **Namanya Juga Hidup** dari layar utama. Layarnya otomatis landscape dan layar penuh.

## Cara main
- Pertama kali: **▶ Mulai Main**, lalu buat karakter dan masuk kota.
- Berikutnya: **▶ Lanjutkan** buat melanjutkan karakter dan progres terakhir.
- **Karakter Baru** menghapus progres otomatis, tapi slot simpan manual (Menu → Simpan) tetap ada.
- Boleh nyalain mode pesawat, gamenya tetap jalan.

## Catatan
- Update APK bisa langsung dipasang di atas versi lama, progres tetap ada, selama tanda tangannya masih sama.
- Kalau aplikasinya di-uninstall atau datanya dihapus (Setelan → Aplikasi → Hapus data), progres ikut hilang.
- Minimal Android 6.0. Di HP kentang, waktu loading pertama bisa lebih lama.
