# Virtual Life — Independent 3D World Builder

This standalone WebGL map editor is preserved independently from the failed Virtual Life Rebuild project.

Features: real 3D geometry and depth testing, isometric camera, object selection and placement, move, rotate, scale, delete, save/export/import JSON. Existing 3D buildings, lamps, benches, and trees use geometric placeholders only. Actor preview is **not** the Virtual Life Online character. It remains a temporary placeholder until canonical online artwork is migrated. Obsolete Rebuild sprite sheets and furniture assets were intentionally not copied.

Open /world-builder/. The production multiplayer game remains separate and unchanged except for relocating script dependencies.
