✳ BANGUN RUANG — QUICK GUIDE
1. Pilih base asli Semesta, lalu edit eksterior modular.
2. Pilih Non-interactive untuk bangunan dekoratif, atau Interactive untuk bangunan yang bisa dimasuki.
3. Interactive: buka INTERIOR untuk memilih room template, menaruh WC/kasur/kursi dan benda lain; buka ACTIONS untuk memeriksa pose Mahluk Hidup.
4. Interior pixel isometric 2:1 memiliki bar furniture scroll horizontal di bawah kanvas: pilih WC, kasur, kursi atau aset lain, lalu tap tile untuk menaruhnya. Exterior punya pilihan Pixel Art / Garis Penanda yang tidak ikut tersimpan.
5. Pixel Creator: Grid ON/OFF (1/4/8/16 px) dan Character ON/OFF menampilkan patokan tubuh native 64×112 di sisi kanvas. Grid dan karakter hanya guide, tidak masuk PNG atau Semesta.
6. Action/interior hanya authoring & editor preview. Multiplayer game utama tidak dijalankan oleh Bangun Ruang.

Penting: penyimpanan bersifat lokal, bukan commit GitHub atau cloud. Export untuk backup lintas perangkat.
